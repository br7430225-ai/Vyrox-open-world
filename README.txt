VYROX OPEN WORLD — Browser Prototype

CONTROLS
- Left virtual stick: move
- Drag the right side of the screen: rotate camera
- RUN: hold to run faster
- JUMP: jump
- ENTER CAR: when near the parked car or bike, enter it
- EXIT: leave vehicle
- RESET: return to start

IMPORTANT
- This prototype uses Three.js from jsDelivr, so the first launch needs an internet connection.
- It is a browser prototype, not an APK and not a finished open-world game.
- The city, player, car, and bike are simple generated 3D shapes. Vehicle handling is arcade-style.
- No real traffic AI, collision physics, missions, saving, or multiplayer are implemented yet.

RUN ON ANDROID (NO PC)
1. Download and extract the ZIP on your phone.
2. Open index.html with a mobile code editor that supports local web preview, OR upload the files to a free static host.
3. Recommended no-PC hosting path: create a free GitHub account, make a public repository, upload index.html, then enable Settings > Pages > Deploy from branch > main / root. Open the generated Pages URL in Chrome.
4. Keep internet enabled because Three.js is imported from a CDN.
5. Use Chrome in landscape orientation for a better experience.

If local file opening blocks JavaScript modules, use a static host URL instead.
